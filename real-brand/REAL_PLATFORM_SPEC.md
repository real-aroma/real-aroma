## 데이터 보호 및 운영 필수
- 인증/권한은 서버에서 강제; UI 숨김만으로 보안 처리하지 않음.
- 신분증/통장사본/계좌/전자도장은 일반 공개 파일 서버에 저장 금지, 암호화·별도 제한 저장 및 접근·발송 감사 로그.
- 신분증은 상시 수집을 기본으로 두지 않고 필요성과 법적 근거 확인, 불필요한 주민등록번호 마스킹, 보유기간 종료시 삭제.
- 대표도 전자도장 사용·신분증 열람은 일반 문서 조회와 별도로 통제하고 본인 승인·목적 기록.
- 강사 계약/동의, 자료 소유 및 퇴회 후 이용범위, 사진 사용 동의, 개인정보처리방침, 보유기간, 백업 복구 정책 수립.
- 사업자별 과세유형/부가세·원천징수는 계약 및 지급조건과 연결하여 확정 전 미리보기.
- 공개 서류에 개인 주민등록번호, 통장번호, 자택 상세 주소 노출 금지.

## 확정 운영 정책 — 2026-10-15
- 최고관리자: 대표 **1인만**. 다른 회원은 최고관리자 권한 부여 불가. 최초 관리자 신원은 서버 측에서 확인 후 단 한 번 부여하며 DB에서 유일성 제약으로 보호.
- 강사 가입: 강사 본인이 신청 → 대기 상태 → 대표 심사 → 승인/반려. 승인 전에는 강사 관리 페이지, 비공개 자료 및 강사 코드 발급 불가.
- 공개 교육안내: 강사 초안 저장 → 대표 승인 → 공개. 초안 수정 이후에는 재승인 필요. 클라이언트 조작으로 published 상태 지정 불가.
- 공식 웹사이트 도메인: **real.aroma1004.com**. 기존 티스토리와 shop 서브도메인은 유지하며, 실제 DNS 및 Vercel 배포는 검증 후 별도로 진행.
- 위 운영 규칙은 데이터베이스 RLS뿐 아니라 서버 API에서 강제한다. 클라이언트 화면 숨김만으로 권한을 처리하지 않는다.
