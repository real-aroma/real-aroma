## 실제 운영에 필요한 외부 설정
1. 새 Supabase 프로젝트 생성 (기존 챌린지 프로젝트 절대 재사용 금지)
2. 대표 개인 로그인 이메일 확정 및 MFA 설정. 이메일과 인증 비밀값을 GitHub에 커밋하지 않음.
3. 새 프로젝트의 URL 및 공개 anon/publishable key를 배포 환경변수로 설정. service_role 비밀 키는 서버 환경에만.
4. 검증용 테스트 계정 3개: 관리자, 강사 A, 강사 B. 교차 계정 조회·수정·상태 전환 거부 확인.
5. 서류 개인정보 처리방침·강사 동의·문서 보존/삭제 기간·사진 공개 동의 양식 검토.
6. 별도 Vercel 프로젝트 root directory를 real-brand로 설정한 후 테스트 주소 검증; 실제 real 서브도메인은 마지막 단계에 연결.
